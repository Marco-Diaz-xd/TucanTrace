TucanTrace: PlantUML (PNG) vs Vectorial (SVG)

Diferencia entre renderizar una imagen de mapa de bits (estática) y un documento vectorial manipulable en el DOM en tiempo real.

1. PlantUML Estático (PNG / Raster)

Es una matriz de píxeles fija. Para iluminar una clase, se debe recompilar todo el texto UML y re-dibujar la imagen completa.

2. Renderizado Vectorial (SVG / DOM Live)

Cada clase y método es un nodo XML. JDI puede cambiar el color, agregar bordes o animar con CSS en 0 milisegundos sin recompilar.
